
# پروژه مانیتورینگ هوشمند شبکه و سرویس‌های لینوکسی

## معرفی پروژه

این پروژه یک برنامه مانیتورینگ شبکه است که با زبان پایتون نوشته شده و وظیفه آن بررسی وضعیت اتصال به سرویس‌ها و پورت‌های مهم شبکه است.

برنامه به‌صورت خودکار و در بازه‌های زمانی مشخص، پورت‌های تعریف‌شده را بررسی می‌کند و مشخص می‌کند که هر سرویس در دسترس است یا خیر.

برای مثال می‌توان از این برنامه برای بررسی پورت‌های زیر استفاده کرد:

- پورت 80 برای HTTP
- پورت 443 برای HTTPS
- پورت 22 برای SSH
- پورت‌های مربوط به پایگاه داده

## امکانات برنامه

- بررسی هم‌زمان چند پورت شبکه
- تشخیص باز یا بسته بودن پورت‌ها
- بررسی اتصال با استفاده از پروتکل TCP
- تعیین زمان انتظار برای هر اتصال (Timeout)
- مدیریت خطاهای شبکه و اتصال ناموفق
- ثبت گزارش‌ها به‌صورت ساختاریافته در قالب JSON
- ذخیره گزارش‌ها در فایل لاگ
- محدود کردن تعداد اتصال‌های هم‌زمان
- امکان تنظیم فاصله زمانی بین هر بار بررسی

## ساختار پروژه

```text
monitor/
│
├── config/
│   └── config.json
│
├── logs/
│   └── monitor.log
│
├── src/
│   ├── __init__.py
│   └── monitor.py
│
├── systemd/
│   └── network-monitor.service
│
├── tests/
│   └── test_monitor.py
│
├── .gitignore
├── README.md
└── requirements.txt
```

توضیح پوشه‌ها و فایل‌ها:

- `config`: شامل تنظیمات برنامه و پورت‌هایی است که باید بررسی شوند.
- `logs`: گزارش‌های اجرای برنامه در این پوشه ذخیره می‌شوند.
- `src`: شامل کد اصلی برنامه است.
- `systemd`: شامل فایل مربوط به اجرای خودکار برنامه در لینوکس است.
- `tests`: شامل تست‌های خودکار برای بررسی عملکرد برنامه است.
- `README.md`: راهنمای معرفی و اجرای پروژه.

## نحوه تنظیم برنامه

تنظیمات برنامه در فایل زیر قرار دارد:

`config/config.json`

در این فایل می‌توان موارد زیر را مشخص کرد:

- `interval_seconds`: فاصله زمانی بین هر بار بررسی بر حسب ثانیه.
- `max_concurrency`: حداکثر تعداد بررسی‌هایی که می‌توانند هم‌زمان انجام شوند.
- `checks`: فهرست سرویس‌هایی که باید بررسی شوند.
- `name`: نام سرویس.
- `host`: آدرس میزبان یا سرور.
- `port`: شماره پورت مورد بررسی.
- `timeout_seconds`: حداکثر زمان انتظار برای برقراری اتصال.

## چرا از Asyncio استفاده شده است؟

در این پروژه از کتابخانه داخلی `asyncio` پایتون استفاده شده است.

فرض کنید قرار باشد وضعیت ۱۰ پورت بررسی شود. در روش معمولی و ترتیبی، برنامه باید منتظر بماند تا بررسی پورت اول تمام شود و سپس سراغ پورت بعدی برود.

اما با استفاده از `asyncio`، برنامه می‌تواند چند بررسی شبکه را به‌صورت هم‌زمان مدیریت کند.

مزایای این روش:

- کاهش زمان انتظار برای بررسی چند سرویس
- استفاده بهتر از منابع سیستم
- جلوگیری از متوقف شدن کل برنامه هنگام انتظار برای پاسخ شبکه

در این پروژه:

- `asyncio.gather` برای اجرای هم‌زمان بررسی‌ها استفاده شده است.
- `asyncio.Semaphore` تعداد عملیات هم‌زمان را محدود می‌کند.
- `asyncio.wait_for` برای تعیین زمان انتظار اتصال استفاده شده است.

## نحوه اجرای برنامه

ابتدا وارد پوشه اصلی پروژه شوید.

سپس دستور زیر را اجرا کنید:

```bash
python -m src.monitor
```

برای متوقف کردن برنامه از کلیدهای `Ctrl + C` استفاده کنید.

## سیستم ثبت گزارش (Logging)

تمام گزارش‌های برنامه در فایل زیر ذخیره می‌شوند:

`logs/monitor.log`

هر گزارش شامل اطلاعاتی مانند موارد زیر است:

- تاریخ و زمان بررسی
- سطح گزارش (INFO یا ERROR)
- نام سرویس
- آدرس میزبان
- شماره پورت
- وضعیت اتصال (UP یا DOWN)
- مدت زمان برقراری اتصال
- علت خطا در صورت ناموفق بودن اتصال

همچنین برای جلوگیری از بزرگ شدن بیش از حد فایل لاگ، از قابلیت چرخش فایل‌های گزارش (Log Rotation) استفاده شده است.

## اجرای تست‌های خودکار

برای بررسی عملکرد برنامه، از کتابخانه داخلی `unittest` پایتون استفاده شده است.

برای اجرای تست‌ها دستور زیر را وارد کنید:

```bash
python -m unittest discover -s tests -v
```

تست‌های نوشته‌شده موارد زیر را بررسی می‌کنند:

1. بارگذاری صحیح فایل تنظیمات
2. شناسایی تنظیمات نامعتبر
3. برقراری موفق اتصال به یک پورت باز
4. تشخیص یک پورت بسته

## راه‌اندازی برنامه در لینوکس با systemd

برای اجرای خودکار برنامه در سیستم‌عامل لینوکس می‌توان از سرویس `systemd` استفاده کرد.

مراحل کلی راه‌اندازی:

1. انتقال پوشه پروژه به مسیر `/opt/network-monitor`
2. ایجاد کاربر اختصاصی برای اجرای سرویس
3. تنظیم دسترسی‌های لازم برای پوشه پروژه و فایل‌های لاگ
4. قرار دادن فایل سرویس در مسیر `/etc/systemd/system/`
5. بارگذاری مجدد تنظیمات systemd
6. فعال‌سازی و اجرای سرویس

دستورات اصلی:

```bash
sudo systemctl daemon-reload
sudo systemctl enable network-monitor
sudo systemctl start network-monitor
```

برای مشاهده وضعیت سرویس:

```bash
sudo systemctl status network-monitor
```

برای مشاهده گزارش‌های سرویس:

```bash
sudo journalctl -u network-monitor -f
```

توجه: راه‌اندازی systemd مخصوص محیط لینوکس است. اجرای برنامه و تست‌های خودکار در ویندوز امکان‌پذیر است، اما عملکرد سرویس systemd باید در یک محیط لینوکسی بررسی شود.
